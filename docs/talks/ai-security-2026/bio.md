# Speaker Bio

Bala Paranj is the founder of Zepho Inc and creator of Stave, an
open-source compound risk reasoning engine for cloud infrastructure.
Stave evaluates 2,650+ security controls across 74 AWS service
domains and exports configuration facts to nine independent
reasoning engines — including Z3, cvc5, and Yices — for formal
verification of cross-service attack paths. Prior to Stave, Bala
built Ephemos, a SPIFFE/SPIRE-based service identity system. He
has deep expertise in distributed systems, formal methods, and
cloud security architecture.
